# Maison Mont-Valérien — Android downloads

This public repository contains **APK release assets only**. Application source code, accounts, backend, guest data, and credentials remain private.

The current Android 0.4.0 is a development preview for testing. The gate's physical actuation is disabled and climate settings are read-only. No real-phone authentication and visual-parity approval has been completed yet.

For the latest supported download, use [the Maison Mont-Valérien Android page](https://traveller.maison-mont-valerien.fr/android/).
